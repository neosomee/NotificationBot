# Telegram-бот напоминаний

Бот принимает от пользователя сообщения в формате  
`01.01.2022 20:00 Сделать домашнюю работу`  
и в указанное время отправляет пользователю напоминание с текстом задачи.

## Функциональность

- Приём сообщений с датой, временем и текстом напоминания в одном сообщении.
- Парсинг даты и времени с помощью регулярных выражений и сохранение задачи в БД.
- Хранение напоминаний в таблице `notification_task` (id, chat_id, notification_text, notification_datetime и доп. поля при необходимости).
- Планировщик, который раз в минуту ищет задачи, время которых совпадает с текущей минутой, и отправляет уведомления в соответствующие чаты.
- Обработка команды `/start` и вывод приветственного сообщения.

## Технологии

- Java 17 ().
- Spring Boot.
- Spring Data JPA.
- Liquibase для миграций БД и создания таблицы `notification_task`
- Любая совместимая СУБД (PostgreSQL)
